## 4. 边界与异常场景

| 类别 | 场景 | 关注点 |
| --- | --- | --- |
| OCR | 纯色/无文字图 | 当前无「无文字跳过识别」预检，仍会触发 WinRT 冷启动；记录耗时 |
| OCR | 超大图片、并发触发两次 OCR | 内存上限、临时 PNG 不互相覆盖、RAII 清理 |
| OCR | WinRT 引擎不可用 / 子进程超时 | 明确错误提示，不卡死 UI |
| 录屏 | 多次暂停/继续、保存目录不可写、FFmpeg 缺失 | 分段拼接时长正确；错误提示可操作；失败文件进入恢复区 |
| 录屏 | 悬浮球入画 | gdigrab 无法排除自身窗口，属已知限制，验收时记录但不判失败 |
| 全局快捷键 | `Alt+V` 被其他程序占用 | 注册失败只告警、不阻断启动 |
| 权限 | 屏幕录制 / 辅助功能权限被拒绝 | 不得报告为已授权；逐项授权与降级提示尚未实现，按已知缺口登记 |

## 5. 回归测试范围

1. **必须执行**：`cargo test --workspace`（README 记录 87 项，含 8 条实机冒烟）、`npm run build`、`npm run check`。
2. **release 验证**：必须用 `npm run tauri -- build --no-bundle`；直接 `cargo build --release` 产出的 exe 未内嵌前端资源，不可用于验收。
3. **契约回归**：命令目录 41 条、事件目录 4 个 id、`OcrResult` / `OcrLine` / `OcrWord` 的 TS 绑定与 JSON Schema 一致性（`orbit-core` 契约测试已覆盖）。
4. **前端回归**：设置面板、圆盘扇区、剪贴板面板；本次未改前端，仅需冒烟。
5. **暂不纳入**：P-01 ~ P-10 性能基线、跨平台矩阵、24 小时长时稳定性、MCP 安全测试——按 README 第八节属于里程碑级测试，需固定设备与采样口径，不能由本次改动验收代替。
